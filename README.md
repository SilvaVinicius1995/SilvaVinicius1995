## Jornada em tecnologia

### 2014-2016
Minha jornada na área de tecnologia começou em 2014 como Trainee IT em uma empresa global líder no mercado de fabricação de tintas e revestimentos. Minhas principais responsabilidades eram:

- Oferecer suporte baseado em patricas do ITIL para vários sistemas, incluindo Ronda - Senior, Fusion - Neomind, Qualitor e GTM.
- Condizir testes completos do sistema para garantir desempenho e confiabilidade ideais.
- Gerenciar projetos de forma eficaz, garantindo entrega bem-sucedida dentro de cronogramas e orçamentos definidos. Colaborando com as partes interessadas para definir e especificar com precisão os requisitos do sistema.
- Fornecer treinamento abrangente ao usuário para facilitar a adoção suave e a utilização eficiente dos sistemas. Criando documentação detalhada e informativa para auxiliar na compreensão e solução de problemas do sistema.
- Executar tarefas administrativas no SAP, incluindo gerenciamento de planilhas de entrada e processos de requisição de compra.

#### Técnologias utilizadas: MSSQL

### 2016-2019
Em 2016, assumi um novo desafio gerenciando e sustentando uma plataforma de integração em uma empresa multinacional líder do mercado de telecomunicações. A plataforma era responsável pelo gerenciamento de assinaturas, cobranças e mensageria relacionadas a produtos VAS. Minhas principais responsabilidades incluíam:

- Definição e especificação de requisitos para uma nova solução de plataforma no âmbito dos Serviços de Valor Agregado (VAS).
- Liderança do projeto de implementação da plataforma VAS, com forte ênfase na geração de valor comercial.
- Condução de testes de integração completos para a plataforma VAS, com foco em áreas críticas como gerenciamento de assinaturas, processos de cobrança, sistemas de mensagens e mecanismos de regras comerciais.
- Execução de implantação contínua da plataforma VAS na infraestrutura LINUX.
- Fornecimento de suporte abrangente para sistemas VAS, resolvendo efetivamente problemas relacionados a OCSG, RabbitMqueue e sistemas de integração.
- Oferta de serviços de consultoria valiosos para clientes no domínio de marketing (MKT).
- Garantia de transição de serviço tranquila e manutenção da excelência operacional, apoiando a equipe de Operações em linha com as práticas ITIL.
- Elaboração de estratégias e design de arquitetura de solução em nuvem usando o Google Cloud Platform (GCP).
- Implementação de processos ETL (Extract, Transform, Load)  usando Pentaho, facilitando a integração e o processamento eficientes de dados.
- Extrair insights valiosos de dados utilizando o poder do BigQuery e apresentá-los de uma maneira visualmente atraente usando o Looker Studio (Antigo Data Studio).

Esses dados incluíam informações sobre ligações, mensagens, tráfego de internet e geolocalização de aparelhos telefônicos. Minhas principais responsabilidades eram:

- Atuar como coordenador técnico, supervisionando e coordenando as atividades das equipes de Dados e DevOps em projetos, garantindo a entrega bem-sucedida do projeto.
- Desenvolver planos e arquiteturas de projeto usando soluções em nuvem, especificamente o Google Cloud Platform.
- Gerenciar o projeto usando a estrutura Scrum/Kanban, garantindo a execução eficiente do projeto.
- Liderar e motivou a equipe técnica, promovendo um ambiente de trabalho colaborativo e produtivo.
- Coletar e documetar requisitos, garantindo uma compreensão clara dos objetivos do projeto.
- Implementar pipelines de dados usando o Cloud Composer (Airflow) e Google Cloud Data Fusion, facilitando os processos de integração e transformação de dados.
- Conduzir atividades de modelagem de dados e criação de schemas, views e tabelas federadas no BigQuery, permitindo organização e armazenamento eficientes de dados.
- fornecer consultoria para clientes, especialmente no setor Judiciário, oferecendo orientação e experiência na alavancagem de soluções baseadas em dados.

Em 2022, integrei o principal time parceiro da Google Cloud nos últimos anos, com foco na fase de design de arquitetura e implementação de projetos de Big Data e IA. Minhas principais responsabilidades eram:

- Elaboração de estratégias e design de arquiteturas baseadas em nuvem para soluções de Big Data, especificamente na Google Cloud Platform.
- Desenvolvimento de propostas técnicas abrangentes para projetos de dados, garantindo alinhamento com os requisitos do cliente e as melhores práticas do setor.
- Liderar a implementação de plataforma de dados, Data Lakes, Data Warehouses (DW) e Datamarts no BigQuery.
  - Implementação de fundação de Cloud, estebelecendo configurações relacionada à estrutura organizacional de recursos de cloud, gestão de identidade (IAM), configurações de rede e segurança.
  - Provisionamento e gerenciamento de recursos na Google Cloud Platform usando Terraform.
  - Implementação esteiras de CICD , utilizando CloudBuild, AzureDevOps e GitLabActions.
  - Criação de pipelines de ingestão de dados baseado em evento utilizando Cloud Functions/Run.
  - Criação e implementação de processos ETL e ELT usando Dataproc, Dataform, AppFlow e AWS Glue.
  - Desenvolvimento de DAGs no Airflow (MWAA e Cloud Composer), utilizando a estrutura Castor e Dag Factory para fluxos de trabalho de dados simplificados e automatizados.
